# Ovok Agent Skill

An agent skill for building, integrating, and troubleshooting applications on Ovok. It combines current Ovok documentation guidance with Ontoly graph-first workflows for codebase questions.

Install with the Skills CLI:

```sh
npx skills add Actimi/ovok-skills --skill ovok
```
